# StemNotes

Лёгкая портативная программа для подбора нот к существующим песням.
Открываете песню → нейросеть разделяет её на дорожки (ударные, бас, гитара, пианино, вокал, остальное),
находит темп и «призрачные» ноты-кандидаты → вы пишете свои ноты в пиано-ролле поверх волны,
спектрограммы и подсказок → экспортируете MIDI в FL Studio.

Работает на Windows 10/11 и Linux. Звук через общий режим (WASAPI shared / PulseAudio), без ASIO,
системный звук продолжает работать.

## Установка (Windows, всё в одной папке, например `D:\StemNotes`)

1. Распакуйте архив в папку на диске D.
2. Запустите `setup_windows.bat`. Скрипт скачает в эту же папку портативный Python 3.12,
   библиотеки, SoundFont GeneralUser GS (32 МБ) и — по вашему согласию — ИИ-модуль
   (PyTorch со сборкой CUDA 12.8 для RTX 50xx, Demucs, Basic Pitch; около 3,5 ГБ).
   Ничего не ставится в систему: Python в `python\`, модели в `models\`, проекты в `projects\`.
3. Запускайте `run.bat`.
4. Для основного движка подбора нот (MuScriptor) один раз настройте доступ к модели, см. раздел
   «MuScriptor: доступ к модели» ниже. Без этого работают остальные движки.

Повторный запуск `setup_windows.bat` безопасен (докачивает недостающее).
`setup_windows.bat --no-ai` — установка без ИИ-модуля.

### MuScriptor: доступ к модели (обязательно для основного движка)

Веса MuScriptor лежат на Hugging Face с ограниченным доступом: их отдают только тому, кто принял
условия лицензии под своим аккаунтом. Поэтому нужен бесплатный аккаунт и токен.

1. Зарегистрируйтесь или войдите на https://huggingface.co.
2. Откройте страницу модели нужного размера и **примите условия** в форме вверху страницы
   (кнопка вида «Agree and access repository»; спросят, кто вы — музыкант/исследователь):
   - https://huggingface.co/MuScriptor/muscriptor-large — лучшее качество, нужна видеокарта (по умолчанию при наличии CUDA)
   - https://huggingface.co/MuScriptor/muscriptor-medium — компромисс (по умолчанию без видеокарты)
   - https://huggingface.co/MuScriptor/muscriptor-small — самый быстрый, годится для процессора
   Условия принимаются отдельно для каждого размера. После принятия вверху страницы должно быть
   написано, что доступ предоставлен.
3. Создайте токен: https://huggingface.co/settings/tokens → **Create new token**, тип **Read**.
   Скопируйте строку целиком (начинается с `hf_`), она показывается один раз.
4. В программе: **ИИ-анализ** → поле **HF token** → вставьте токен, выберите размер модели в списке
   «MuScriptor модель» и нажмите «Запустить». Токен сохраняется в `settings.json` в папке программы,
   второй раз вводить не нужно.

При первом анализе модель скачивается один раз в `models\huggingface` (small ≈ 0,4 ГБ, medium ≈ 1,2 ГБ,
large ≈ 5,6 ГБ). Если в конце анализа появилось окно «Hugging Face отказал в доступе», проверьте два
момента: условия приняты именно на странице выбранного размера, и в поле вставлен действующий токен.

Лицензия модели: CC BY-NC 4.0 плюс условия авторов (Kyutai и Mirelo). Коротко: бесплатно для личного
и некоммерческого использования; продавать транскрипции или сервис на её основе нельзя; пользователь
сам отвечает за права на музыку, которую транскрибирует. Код StemNotes и остальные движки этого
ограничения не имеют.

## Как работать

1. **Открыть песню** (Ctrl+O): mp3/wav/flac/ogg/m4a. Создаётся проект `projects\<имя песни>\`,
   песня копируется в него.
2. **ИИ-анализ** (Ctrl+I): темп и сетка, разделение на стемы (Demucs `htdemucs_6s`),
   спектрограммы, призрачные ноты (Basic Pitch) и удары (детектор ударных).
   На RTX 5060 Ti разделение 4-минутной песни занимает около 20–40 секунд, транскрипция всех стемов
   ещё около минуты на процессоре. Первый запуск скачивает модель (≈80 МБ) в `models\`.
3. После анализа появляются аудиодорожки (оригинал + стемы) и MIDI-дорожки (Бас, Ударные, Гитара…).
   У каждой MIDI-дорожки выбран **источник** (стем): он задаёт, чья волна, спектрограмма и призрачные
   ноты показываются в фоне.
4. Выберите MIDI-дорожку слева, заглушите лишнее (кнопки **M/S**, «Все выкл», «Только активная»)
   и пишите ноты. Призрачные ноты — жёлтые пунктирные с процентом уверенности, их может быть
   несколько на один момент (например 90% / 50% / 30%). Они только подсказка: ноты вы ставите сами.
5. **Экспорт MIDI** (Ctrl+E): один `.mid`, каждая дорожка на своём канале с названием и GM-инструментом,
   ударные на канале 10. В FL Studio: File → Import → MIDI file. При экспорте «выровнять по началу
   песни» нулевое время MIDI совпадает с началом аудиофайла.

### Несколько движков подбора нот

Основной движок — **MuScriptor**: он один раз проходит по всей песне и раскладывает ноты по инструментам,
включая ударные. В окне анализа можно включить и другие движки; их кандидаты рисуются разными цветами,
а в панели «Слои» каждый движок включается и выключается отдельно. Так можно сравнить, кто лучше
угадал партию, и оставить один или смотреть все сразу.

**Перенести в дорожку**: в панели «Слои» выберите движок и нажмите «Скопировать ноты в дорожку» — его
призрачные ноты станут обычными нотами активной MIDI-дорожки, которые дальше правятся руками
(Ctrl+Z отменяет). Галочки: только участок цикла; привязать к сетке.

| Движок | Для чего | Цвет |
|---|---|---|
| Basic Pitch (Spotify) | любой инструмент, полифония, карта вероятностей | жёлтый |
| CREPE | одноголосные партии: бас, вокал; очень точная высота | голубой |
| pYIN | то же без нейросети, быстрый (по умолчанию выключен) | зелёный |
| Piano Transcription (ByteDance) | фортепиано, лучшее качество; модель ~170 МБ скачивается в `models` | оранжево-красный |
| MuScriptor (вся песня) | Kyutai/Mirelo, один проход по оригиналу: ноты раскладываются по стемам по инструменту, который опознала модель; процент показывает, звучит ли стем под нотой | розовый |
| MuScriptor (по стемам) | тот же MuScriptor отдельно на каждом стеме Demucs, чужие инструменты запрещены; надёжнее для баса и пианино | сиреневый |
| Детектор ударов | ударные: бочка / малый / хэт / тарелка | жёлтый |

MuScriptor различает три вида гитары (акустика, чистая электро, перегруз) и несколько видов клавишных
(пианино, электропиано, орган, перкуссия). В панели «Слои» эти группы появляются отдельными отключаемыми
наборами под движком «по стемам», каждая своим цветом: так две разные по тембру гитары видны раздельно.
Две гитары одного тембра ни одна модель пока не разделяет.

**MuScriptor** выдаёт готовое решение без процентов, поэтому его ноты рисуются одним тоном.
Как получить доступ к модели (принять условия на Hugging Face и вставить токен) — в разделе
«MuScriptor: доступ к модели» выше.

Карта «ИИ-вероятности» показывается для движка, выбранного в списке «Карта» панели «Слои».

### Фон для каждого инструмента отдельно

Фон (волна, спектрограмма, ИИ-вероятности, призрачные ноты) берётся из **стема, выбранного у активной
MIDI-дорожки** — поле «Фон:» в строке дорожки слева. После анализа у «Бас» стоит стем «Бас», у «Ударные» —
«Ударные» и т.д.; переключили дорожку — поменялся фон. Пока анализ с разделением на стемы не выполнен,
единственный доступный источник — «Оригинал» (вся песня целиком).
В панели «Слои» поле «Источник фона» может принудительно показать любой стем вне зависимости от дорожки.
Слой «Другие дорожки» (ноты остальных MIDI-дорожек) по умолчанию выключен.

### Слои фона (панель справа)

| Слой | Что показывает |
|---|---|
| Волна | форма волны стема: где звук, где тишина |
| Спектрограмма | энергия по высотам (CQT, строки совпадают с клавишами) |
| ИИ-вероятности | тепловая карта нейросети: вероятность ноты в каждый момент |
| Призрачные ноты | кандидаты с процентом; порог «Скрывать ниже» убирает слабые |
| Другие дорожки | ноты остальных MIDI-дорожек бледным цветом |
| Найденные доли | розовые метки долей из детектора темпа (у линейки) |

Источник фона: «Как у дорожки» или любой стем вручную.

### Управление в пиано-ролле

- ЛКМ по пустому месту — новая нота, тянуть — длина. ЛКМ по ноте — двигать, за правый край — длина.
- ПКМ — удалить (можно вести мышью). Shift+ЛКМ — добавить к выделению. Ctrl+ЛКМ по пустому — рамка.
- Ctrl+тянуть ноту — копия. Del — удалить. Ctrl+Z / Ctrl+Y — отмена/повтор. Ctrl+C/V/X, Ctrl+D — дубль.
- Стрелки — сдвиг выделенного (вверх/вниз на полутон, Ctrl — на октаву). `+`/`−` — velocity.
- Колесо — вверх/вниз, Shift+колесо — влево/вправо, Ctrl+колесо — зум по времени, Alt+колесо — по высоте.
- Линейка: клик — позиция, тянуть — участок цикла (кнопка «Цикл» / L), ПКМ — убрать цикл.
- Пробел — играть/пауза (работает при любом фокусе), Home — в начало, Esc — пауза. Клик по клавише слева — послушать ноту.

### Темп и сетка

Ноты хранятся в долях. BPM и «Сдвиг сетки» (время первой доли) определяются анализом, их можно
поправить вручную. Если детектор нашёл удвоенный/половинный темп — кнопки «½ BPM» и «×2 BPM».
Меняйте темп **до** того, как написали много нот: при смене BPM ноты сдвигаются относительно аудио.

### Инструменты

- Встроенные: любой из 128 General MIDI инструментов SoundFont + ударные
  (быстрый выбор: ударные, пианино, бас, гитара акустика/рок, скрипка, духовые…).
  Можно положить другой `.sf2` в папку `soundfonts\`.
- **VST3**: кнопка инструмента → вкладка «VST3 плагин» (ищутся `C:\Program Files\Common Files\VST3`
  и папка `vst3\` рядом с программой, либо выбрать файл). VST3-дорожки играют в реальном времени через
  нативный аудиохост (см. «Как устроен звук»). Кнопка «Окно VST» открывает интерфейс плагина как в обычном DAW,
  программа при этом не блокируется; закрывается окно своим крестиком или кнопкой «Закрыть окно VST».
  Состояние плагина сохраняется в проекте. «Тест VST» прогоняет ноту через плагин и показывает пик.
  Проверено на Windows: EZdrummer 3, Ample Metal R, MODO BASS 2.

## Обновление

Код программы обновляется из GitHub (`Hani-NE-Git/StemnotesAI`), **не трогая** `python\`, `models\`,
`soundfonts\`, `projects\`, `cache\` и `settings.json`:

- в программе: кнопка **«Обновить»** → «Проверить и обновить» → «Перезапустить программу»;
- или `update.bat` (Linux: `./update.sh`), ключ `--force` переустанавливает код той же версии.

Если изменились файлы `requirements-*.txt`, обновятся и библиотеки (pip докачивает только новое).

Git для обновления не нужен: программа скачивает zip-архив ветки `main` и заменяет только изменившиеся
файлы кода. Если папка программы является git-клоном и git установлен, используется `git fetch` + `git merge`.
Другой репозиторий/ветка задаются в `settings.json`: `"github_repo": "owner/repo"`, `"github_branch": "main"`;
для приватного форка — `"github_token": "github_pat_..."`.

## Как устроен звук

Звук и VST3 обслуживает **нативный аудиохост `stemnotes-host`** (C++, JUCE — та же библиотека, на которой
написано большинство VST-хостов и сами плагины). Он живёт в папке `bin\`, запускается программой как отдельный
процесс и получает команды по каналу. В нём в реальном времени играют стемы, SoundFont и VST3-инструменты,
окна плагинов открываются как в обычном DAW и ничего не блокируют. Исходники хоста в папке `host\`, собирает
их GitHub Actions (`.github/workflows/build-host.yml`), готовый бинарник лежит в релизе `host-latest`; программа
скачивает его сама при первом запуске или по кнопке. Если хоста нет, используется прежний Python-движок без VST3.
Переключение: `"audio_backend": "native"` или `"python"` в `settings.json`. Журнал хоста: `logs\stemnotes-host.log`
(туда же попадает отладочный вывод самих плагинов).

Проверка хоста с плагинами без звуковой карты: `host\tools\vst_smoke_test.py` загружает каждый плагин, играет
несколько нот и печатает пик, например
`python host\tools\vst_smoke_test.py "C:\Program Files\Common Files\VST3\EZdrummer 3.vst3=36,38,42"`.
Номер версии хоста задаётся одним файлом `host\VERSION`: при любом изменении `host\` его нужно поднять,
иначе программа не предложит скачать новую сборку.

### Старый Python-движок

Звук живёт в отдельном процессе (`stemnotes-audio`): устройство вывода, SoundFont и VST3-плагины загружены
там, а интерфейс только посылает команды. Поэтому тяжёлая перерисовка, анализ или загрузка плагина не могут
вызвать хрипы. Если по какой-то причине процесс не стартует, программа автоматически переходит на старый
режим «в одном процессе» (в окне «Звук…» это видно по строке «отдельный аудиопроцесс: нет»). Принудительно
старый режим включается строкой `"audio_inprocess": true` в `settings.json`.

VST3 (экспериментально): хостинг через Pedalboard. После выбора плагина кнопка **«Тест VST»** прогоняет через
него одну ноту и сообщает, вернул ли он звук. **«Окно VST»** открывает интерфейс плагина; пока окно открыто,
другие операции с плагинами ждут, та же кнопка («Закрыть окно VST») закрывает его. Настройки сохраняются в
проект при закрытии окна. Простые синтезаторы работают, коммерческие сэмплерные инструменты (EZdrummer,
Ample, IK Multimedia) через Pedalboard, как правило, не звучат: для них нужен полноценный хост.
Все операции с VST3 записываются в `logs\stemnotes.log`.

## Ограничения

- Экспорт только в MIDI (формат .flp закрытый). FL Studio импортирует MIDI с сохранением дорожек.
- Призрачные ноты для ударных — эвристика (бочка/малый/хэт/тарелка по спектру), точность ниже, чем у
  нейросети для тональных инструментов.
- Гитара и пианино у Demucs разделяются хуже, чем бас и ударные; для них полезно смотреть ещё и
  спектрограмму стема «Остальное» или «Оригинал».
- Задержка звука в общем режиме около 20–40 мс: нормально для набора нот, не для живой игры.

## Если что-то не так

- **Журнал**: `logs\stemnotes.log` в папке программы (кнопка «Открыть журнал» в окне анализа). Там видно,
  какой движок какой файл получал (`file=...stems\bass.wav` для режима по стемам), сколько нот нашёл и
  ошибки. Присылайте его при проблемах.

- **Нет звука**: кнопка «Звук…» → выберите устройство (на Windows предпочтительно с пометкой WASAPI).
- **Хрипит / трещит**: кнопка «Звук…» → увеличьте «Буфер» (2048 или 4096). Это добавляет задержку при
  прослушивании нот, но убирает пропуски. Убедитесь, что не включены одновременно «Оригинал» и все стемы:
  их сумма вдвое громче (после анализа «Оригинал» заглушается автоматически).
- **«no kernel image is available»** при анализе: переустановите torch сборкой cu128:
  `python\python.exe -m pip install -U torch --index-url https://download.pytorch.org/whl/cu128`
- **Файл .m4a/.aac не открывается** на Linux: сконвертируйте в wav/flac/mp3.
- **Анализ упал из-за памяти GPU**: выберите модель `htdemucs` (4 стема) в окне анализа.
